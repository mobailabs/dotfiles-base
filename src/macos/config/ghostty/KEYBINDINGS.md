# Ghostty + tmux 快捷键速查表

所有快捷键映射到 macOS `⌘ Command` 键，对应 tmux 前缀键 `Ctrl+B`。Ghostty 默认不会自动启动 tmux，需要先手动进入 tmux 会话。

## 💡 使用技巧

### 推荐工作流
```
1. 打开项目
   cd ~/projects/myproject
   tmux new -A -s "$(basename "$PWD")"

2. 分割面板
   ⌘Enter  左右分割（编辑器 | 终端）
   ⌘D      上下分割

3. 导航面板
   ⌘H/J/K/L  Vim 风格快速切换

4. 缩放面板
   ⌘Z  临时全屏当前面板

5. 多窗口工作
   ⌘T     新建窗口
   ⌘1-9   快速切换
```

### tmux 原生快捷键

在 tmux 内部，仍然可以使用原生快捷键：

```
Ctrl+B ?        显示所有快捷键
Ctrl+B :        进入命令模式
Ctrl+B [        进入复制模式
Ctrl+B ]        粘贴
Ctrl+B Tab      切换到最后一个面板
```

### 面板调整技巧

按住 `⌘⇧` 然后连续按 `H/J/K/L` 可以精细调整面板大小：
- 每次按压调整 5 个单位
- 需要在 tmux 配置中设置步长

## 🔍 故障排查

### 快捷键不响应？

```bash
# 1. 确认 tmux 正在运行
echo $TMUX

# 2. 检查 tmux 前缀键配置
tmux show-options -g | grep prefix
# 应显示: prefix C-b

# 3. 验证快捷键绑定
tmux list-keys | grep "C-b"
```

### 如何按项目目录命名会话？

默认不自动启动 tmux，可以在项目目录里手动创建会话：
```bash
cd ~/projects/myproject
tmux new -A -s "$(basename "$PWD")"
```
